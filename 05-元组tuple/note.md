# 1. 元组 `tuple`

Python 使用 `tuple` 表示元组。

例如：

```python
t = (1, 2, 3)
```

打印：

```python
print(t)
```

输出：

```text
(1, 2, 3)
```

查看类型：

```python
print(type(t))
```

结果：

```text
<class 'tuple'>
```

元组和列表一样，都可以按照一定顺序保存多个元素。

但是两者有一个非常重要的区别：

```text
list  → 可变
tuple → 不可变
```

因此，元组最重要的特点可以记成：

```text
tuple → 有序、不可变
```

---

# 2. 创建元组

元组通常使用：

```text
()
```

表示。

元素之间使用逗号：

```text
,
```

分隔。

例如：

```python
t = (1, 2, 3)
```

也可以保存字符串：

```python
names = ('Michael', 'Bob', 'Tracy')
```

基本形式：

```python
元组名 = (元素1, 元素2, 元素3, ...)
```

---

# 3. 空元组

如果元组中没有任何元素，可以创建一个空元组：

```python
t = ()
```

打印：

```python
print(t)
```

输出：

```text
()
```

查看长度：

```python
print(len(t))
```

输出：

```text
0
```

因此：

```text
() → 空元组
```

---

# 4. 单元素元组

只有一个元素的元组写法比较特殊。

如果写：

```python
t = (1)
```

这里的 `t` 并不是元组。

查看类型：

```python
print(type(t))
```

结果：

```text
<class 'int'>
```

因为：

```text
(1)
```

中的括号会被 Python 当成普通的运算分组括号。

如果需要创建只有一个元素的元组，必须写：

```python
t = (1,)
```

查看类型：

```python
print(type(t))
```

结果：

```text
<class 'tuple'>
```

因此需要特别注意：

```text
(1)  → int

(1,) → tuple
```

---

# 5. 为什么单元素元组需要逗号

Python 中的小括号本身还有一个作用：

```text
改变表达式的运算顺序
```

例如：

```python
(1 + 2) * 3
```

所以：

```python
(1)
```

无法单独表示“这是一个元组”。

真正让 Python 判断这是元组的重要标志之一是：

```text
逗号 ,
```

因此：

```python
t = (1,)
```

才表示只有一个元素的元组。

可以重点记住：

```text
单元素 tuple 一定不要漏掉逗号
```

---

# 6. 元组索引

元组和列表一样支持索引访问。

例如：

```python
t = (1, 2, 3)

print(t[0])
```

输出：

```text
1
```

索引仍然从：

```text
0
```

开始。

对应关系：

```text
索引      0     1     2
          ↓     ↓     ↓
元素      1     2     3
```

因此：

```python
t[0]
```

表示第一个元素。

```python
t[1]
```

表示第二个元素。

---

# 7. 元组的负索引

元组同样支持负索引。

例如：

```python
t = (1, 2, 3)

print(t[-1])
```

输出：

```text
3
```

正负索引关系：

```text
正索引       0       1       2
             ↓       ↓       ↓
元素         1       2       3
             ↑       ↑       ↑
负索引      -3      -2      -1
```

因此：

```python
t[0]      # 第一个元素

t[-1]     # 最后一个元素
```

这部分规则和 `list` 相同。

---

# 8. `len()` 获取元组长度

使用：

```python
len()
```

可以获取元组中的元素数量。

例如：

```python
t = (1, 2, 3)

print(len(t))
```

输出：

```text
3
```

因此：

```text
len(tuple) → 元组中的元素数量
```

---

# 9. 元组不可修改

元组和列表最大的区别是：

```text
tuple 不可变
```

例如：

```python
t = (1, 2, 3)
```

如果执行：

```python
t[0] = 10
```

会产生：

```text
TypeError
```

因为元组创建之后，不能直接修改其中某个位置的元素。

也就是说：

```python
t[0] = 10
```

这种操作对于元组是不允许的。

---

# 10. 元组不能增、删、改元素

由于元组是不可变对象，所以创建之后不能直接改变其元素结构。

列表中可以进行：

```python
L.append(x)
L.insert(i, x)
L.pop()
L.remove(x)
L[i] = x
```

但是元组不能通过这些方式进行增、删、改。

可以简单理解为：

```text
tuple 创建完成
      ↓
元素位置和指向关系固定
      ↓
不能直接增、删、改
```

因此：

```text
list  → 创建后仍然可以修改

tuple → 创建后不能直接修改
```

---

# 11. 元组中包含列表

元组虽然不可变，但元组内部可以包含可变对象。

例如：

```python
t = ('a', 'b', ['X', 'Y'])
```

这里：

```text
'a'          → str
'b'          → str
['X', 'Y']   → list
```

整个结构可以表示为：

```text
tuple
 │
 ├── 'a'
 ├── 'b'
 └── list
      │
      ├── 'X'
      └── 'Y'
```

---

# 12. 元组中的列表内容可以修改

例如：

```python
t = ('a', 'b', ['X', 'Y'])

print("修改前:", t)

t[2][0] = 'M'
t[2][1] = 'N'

print("修改后:", t)
```

输出：

```text
修改前: ('a', 'b', ['X', 'Y'])

修改后: ('a', 'b', ['M', 'N'])
```

看起来好像：

```text
tuple 被修改了
```

但实际上修改的是：

```text
tuple 内部 list 的内容
```

而不是元组本身的位置关系。

---

# 13. 理解元组的“不可变”

元组的不可变主要指：

```text
元组中每个位置所指向的对象不能被直接替换
```

例如：

```python
t = ('a', 'b', ['X', 'Y'])
```

可以理解为：

```text
t[0] ─────→ 'a'

t[1] ─────→ 'b'

t[2] ─────→ ['X', 'Y']
```

这些指向关系不能直接修改。

例如：

```python
t[0] = 'c'
```

不允许。

但是：

```python
t[2][0] = 'M'
```

修改的是 `t[2]` 指向的那个列表内部的内容。

原来：

```text
t[2]
  │
  ↓
['X', 'Y']
```

修改后：

```text
t[2]
  │
  ↓
['M', 'Y']
```

`t[2]` 仍然指向原来的那个列表对象，只是列表内部发生了变化。

因此：

```text
tuple 自身不可变
        ↓
如果内部元素本身是可变对象
        ↓
这个可变对象内部仍然可能发生变化
```

# 14. 元组解包 `unpacking`

元组支持**解包（unpacking）**。

例如：

```python
x, y, z = (10, 20, 30)

print(x, y, z)
```

输出：

```text
10 20 30
```

这个过程相当于：

```text
(10, 20, 30)
  ↓   ↓   ↓
  x   y   z
```

最终：

```text
x = 10
y = 20
z = 30
```

因此：

```python
x, y, z = (10, 20, 30)
```

可以一次将元组中的多个元素分别赋值给多个变量。

---

# 15. 解包时数量需要对应

普通解包时，左边变量的数量需要和右边元素的数量对应。

例如：

```python
x, y, z = (10, 20, 30)
```

对应关系：

```text
x ← 10
y ← 20
z ← 30
```

如果元素数量和变量数量不匹配，普通解包就无法按照这种方式完成。

因此可以先记成：

```text
变量数量 ↔ 元素数量
```

---

# 16. `*` 收集剩余元素

解包时还可以使用：

```text
*
```

收集剩余元素。

例如：

```python
a, *rest = (1, 2, 3, 4)

print(a)
print(rest)
```

结果：

```text
1
[2, 3, 4]
```

整个过程可以理解为：

```text
(1, 2, 3, 4)
 │  └────┬────┘
 ↓       ↓
 a     *rest
```

因此：

```text
a = 1

rest = [2, 3, 4]
```

需要注意，`*rest` 收集到的剩余元素会形成：

```text
list
```

---

# 17. 列表也可以进行解包

解包并不是 `tuple` 独有的操作。

例如列表：

```python
a, b, c = [1, 2, 3]

print(a, b, c)
```

同样可以得到：

```text
1 2 3
```

因此：

```text
tuple 可以解包
list  也可以解包
```

这一部分学习元组时比较常见，所以需要能够识别这种写法。

# 18. 函数返回多个值与元组

Python 函数返回多个值时，可以写：

```python
return a, b
```

这种写法可以理解为返回：

```python
(a, b)
```

例如：

```python
def get_point():
    return 10, 20
```

调用：

```python
result = get_point()

print(result)
```

可以得到类似：

```text
(10, 20)
```

因此：

```python
return a, b
```

可以理解为：

```python
return (a, b)
```

再配合解包：

```python
x, y = get_point()
```

就可以分别得到返回的多个值。

# 19. 元组作为字典的键

元组还可以作为字典 `dict` 的键。

例如：

```python
d = {
    (1, 2): "point A",
    (3, 4): "point B"
}

print(d[(1, 2)])
```

输出：

```text
point A
```

这里：

```python
(1, 2)
```

作为字典的 key。

因此可以出现：

```text
(1, 2) → "point A"

(3, 4) → "point B"
```

---

# 20. 元组与可哈希

字典的 key 需要是可以进行哈希的对象。

元组在其元素也满足可哈希要求时，可以作为字典的 key。

例如：

```python
d = {
    (1, 2): "point A"
}
```

是可以使用的。

而列表属于可变对象，不能直接作为字典的 key：

```python
# 错误示例
d = {
    [1, 2]: "point A"
}
```

因此可以先建立基本区别：

```text
tuple → 在元素满足要求时可以作为 dict 的 key

list  → 不能作为 dict 的 key
```

# 21. `list` 转换为 `tuple`

Python 可以使用：

```python
tuple()
```

把列表转换为元组。

例如：

```python
lst = [1, 2, 3]

tpl = tuple(lst)

print(tpl)
```

输出：

```text
(1, 2, 3)
```

因此：

```text
list
 ↓
tuple()
 ↓
tuple
```

例如：

```text
[1, 2, 3]
     ↓ tuple()
(1, 2, 3)
```

---

# 22. `tuple` 转换为 `list`

反过来也可以使用：

```python
list()
```

把元组转换为列表。

例如：

```python

lst = list(tpl)

print(lst)
```

输出：

```text
[1, 2, 3]
```

因此：

```text
tuple
 ↓
list()
 ↓
list
```

例如：

```text
(1, 2, 3)
     ↓ list()
[1, 2, 3]
```

---

# 23. `list` 与 `tuple` 相互转换

两者之间的转换可以统一记成：

```text
             tuple()
list  --------------------> tuple


             list()
list  <-------------------- tuple
```

例如：

```python
lst = [1, 2, 3]

tpl = tuple(lst)

back_to_list = list(tpl)
```

变化过程：

```text
[1, 2, 3]
     ↓
  tuple()
     ↓
(1, 2, 3)
     ↓
   list()
     ↓
[1, 2, 3]
```

# 24. `tuple` 和 `list` 的区别

元组和列表都属于有序的数据结构，也都支持索引访问。

但是两者最重要的区别是：

```text
list  → 可变
tuple → 不可变
```

可以整理为：

| 特点 | `list` | `tuple` |
| --- | --- | --- |
| 写法 | `[1, 2, 3]` | `(1, 2, 3)` |
| 是否有序 | 是 | 是 |
| 支持索引 | 是 | 是 |
| 支持负索引 | 是 | 是 |
| 是否可修改 | 可以 | 不可以直接修改 |
| 添加元素 | 可以 | 不可以 |
| 删除元素 | 可以 | 不可以 |
| 修改元素 | 可以 | 不可以 |
| 解包 | 可以 | 可以 |
| 作为 `dict` 的 key | 不可以 | 满足可哈希要求时可以 |

最核心的区别仍然是：

```text
list  = 有序 + 可变

tuple = 有序 + 不可变
```

# 25. 为什么使用元组

如果一组数据创建之后不希望被随意修改，可以考虑使用元组。

例如一个二维坐标：

```python
point = (10, 20)
```

如果这个坐标在后续程序中应该作为一组固定的数据存在，那么使用 `tuple` 可以直接体现：

```text
这组数据不准备被修改
```

元组的不可变性还使它在满足条件时可以用于一些列表不能使用的场景，例如：

```text
作为 dict 的 key
```

因此可以简单理解为：

```text
需要频繁修改数据
        ↓
       list


数据创建后不准备修改
        ↓
       tuple
```

# 🔗 `list` 与 `tuple` 的关系

这一节最重要的是建立 `list` 和 `tuple` 之间的联系：

```text
                    有序序列
                       │
             ┌─────────┴─────────┐
             │                   │
            list               tuple
             │                   │
            可变                不可变
             │                   │
       [1, 2, 3]            (1, 2, 3)
             │                   │
             │     tuple()       │
             ├──────────────────>│
             │                   │
             │      list()       │
             │<──────────────────┤
             │                   │
       可以增删改            不能直接增删改
```

索引访问方式基本一致：

```python
L[0]
L[-1]

t[0]
t[-1]
```

所以可以把两者的核心区别记成：

```text
list
↓
需要修改的数据


tuple
↓
创建后不准备修改的数据
```
