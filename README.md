## 🧠 Notes Style

每一部分的学习笔记会尽量按照统一的方式整理：

- 📌 **核心知识点** —— 当前内容涉及的重要概念
- 💻 **代码示例** —— 用实际代码理解语法
- 🔍 **运行结果** —— 对照代码观察程序行为
- 🧠 **原理理解** —— 不只记住写法，也理解为什么
- ⚠️ **易错点** —— 记录学习过程中容易混淆的地方
- 🔗 **知识联系** —— 将新知识和之前的内容连接起来
- ✅ **阶段总结** —— 整理当前阶段真正需要掌握的内容

目标不是简单地把代码跑通，而是逐渐形成可以回顾和复用的 Python 知识体系。

## 🔄 Learning Workflow

整个仓库采用 Git 记录学习过程：

```text
学习新的知识
      ↓
编写 / 运行代码
      ↓
理解运行结果
      ↓
整理 README 笔记
      ↓
Git Commit
      ↓
Push to GitHub
      ↓
继续下一部分
```

常用 Git 工作流：

```bash
git status
git add .
git commit -m "更新Python学习笔记"
git push
```

每一次 Commit 都是学习过程中的一个小节点。
